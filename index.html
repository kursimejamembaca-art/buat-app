Buat Aplikasi dan Game Android Otomatis

Gambar masuk ke assets/images/, suara ke assets/audio/. Gunakan nama file tanpa spasi, misalnya kucing.png.
Langkah manual (hanya jika upload otomatis gagal):
1. Unduh kedua file di bawah.
2. Di Codemagic: Team settings → Code signing identities → Android keystore → Add keystore.
3. Upload file .p12. Reference name huruf kecil semua: upload_keystore
4. Alias: upload. Keystore password dan Key password: isi dari file key.txt.
5. Simpan, lalu tekan tombol di bawah.
